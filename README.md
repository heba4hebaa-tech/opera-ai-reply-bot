# 🤖 تطبيق الرد الذكي — واتساب + مسنجر + متجر ولوحة أدمن

🌐 **النسخة المنشورة:** https://opera-ai-reply-bot.onrender.com
📦 **المصدر:** https://github.com/heba4hebaa-tech/opera-ai-reply-bot

تطبيق ويب **مجاني بالكامل** وبدون أي مكتبات خارجية (Node.js مدمج + SQLite مدمج):

- **رد تلقائي ذكي** على رسائل الزبائن في **واتساب** و**المسنجر** عبر Meta Graph API الرسمية.
- **لوحة أدمن** لإدارة الأصناف والمنتجات والأسعار والأسئلة الشائعة والطلبات والمحادثات.
- **متجر للزبائن** يعرض المنتجات ويسمح بإنشاء طلب مباشرة.
- **قاعدة معرفة** تُحقن فيprompt الذكاء الاصطناعي كي يجيب من بيانات متجرك الفعلية (أسعار/منتجات/توصيل/دفع) ولا يخترع معلومات.
- يعمل أيضاً **بدون مفاتيح** في وضع تجريبي: الردود الأساسية تعمل والمحادثات تُحفظ في لوحة الأدمن.

## 1) التشغيل

1. ثبّت Node.js **22.5 أو أحدث** من https://nodejs.org
2. افتح `start.bat` (أو شغّل `node --no-warnings server/index.js`)
3. افتح المتجر: http://localhost:3000/
4. افتح الأدمن: http://localhost:3000/admin — الدخول الافتراضي `admin` / `admin123`
   > غيّر كلمة المرور فوراً من: لوحة الأدمن ← كلمة المرور.

لا يوجد `npm install` — التطبيق يعتمد على مكتبات Node المدمجة فقط.

---

## 2) تفعيل الذكاء الاصطناعي (مجاني)

1. افتح https://aistudio.google.com/app/apikey وأنشئ مفتاح API مجاني.
2. في ملف `.env` ضع:
   ```
   GEMINI_API_KEY=مفتاحك_هنا
   GEMINI_MODEL=gemini-2.5-flash
   ```
3. أعد تشغيل التطبيق. يمكنك تغيير النبرة وإيقاف/تفعيل الرد الذكي من لوحة الأدمن ← الإعدادات.

> إذا تعذّر الاتصال بـ Gemini أو انتهت الحصة المجانية، يعود التطبيق تلقائياً للردود الأساسية بالعربية.

---

## 3) ربط واتساب (WhatsApp Cloud API — مجاني)

1. افتح https://developers.facebook.com → أنشئ تطبيقاً من نوع **Business**.
2. أضف منتج **WhatsApp** → من تبويب **API Setup** احصل على:
   - `Phone number ID`
   - access token مؤقت (للاختبار) أو أنشئ **System User Token** دائم من Business Settings.
3. في `.env`:
   ```
   WA_PHONE_NUMBER_ID=رقم_الهاتف_من_فيسبوك
   WA_ACCESS_TOKEN=التوكن_الخاص_بك
   ```
4. في إعدادات Webhook داخل التطبيق:
   - Callback URL: `https://YOUR_DOMAIN/webhooks/whatsapp`
   - Verify token: نفس القيمة في `.env` (`VERIFY_TOKEN`)
   - اشترك في حقل `messages`.

للاختبار المحلي استخدم نفقاً مجانياً مثل `ngrok http 3000` وضع الرابط الناتج في Meta.

---

## 4) ربط مسنجر (Messenger — مجاني)

1. في نفس تطبيق Meta، أضف منتج **Messenger** واربطه بصفحة فيسبوك الخاصة بك.
2. أنشئ **Page Access Token** من إعدادات Messenger (أو من Graph API Explorer).
3. في `.env`:
   ```
   MESSENGER_PAGE_TOKEN=توكن_الصفحة
   ```
4. Webhook:
   - Callback URL: `https://YOUR_DOMAIN/webhooks/messenger`
   - Verify token: نفسه (`VERIFY_TOKEN`)
   - اشترك في `messages`, `messaging_postbacks`, `message_reactions`.

5. اختياري — لتأمين Webhooks ضع `META_APP_SECRET` (App Secret) في `.env`، وسيتحقق السيرفر من توقيع `X-Hub-Signature-256`.

---

## 5) نشر مجاني (دائم)

منصات مجانية تدعم Node.js و HTTPS (مطلوب لـ Webhooks):

- **Render**: https://render.com ← New Web Service ← ربط المستودع ← Command: `node --no-warnings server/index.js`.
- **Railway**: https://railway.app ← New Project ← Deploy from GitHub.
- أضف متغيرات `.env` نفسها في لوحة المنصة (بدون رفع ملف `.env`).
- قاعدة البيانات تُ-created تلقائياً في `data/app.db`، وللحفظ الدائم أضف قرصاً (Persistent Disk) على Render/Railway.

## 6) الاستخدام

- **الأدمن**: الأصناف ← المنتجات ← الأسئلة الشائعة ← الإعدادات. كل تعديل ينعكس فوراً على ردود المساعد.
- **اختبار الرد**: لوحة الأدمن ← «اختبار الرد» — جرّب رسائل مثل `المنتجات`، `كم السعر؟`، `أريد الطلب`.
- **المحادثات**: هنا تظهر كل رسائل واتساب/مسنجر وردود المساعد.
- **الطلبات**: تُ-created من المتجر، ويمكن تغيير حالتها (جديد ← قيد التحضير ← تم الشحن ← مكتمل).

### أوامر سريعة يفهمها المساعد
`المنتجات` · `الكتالوج` · `الأسعار` · `أريد الطلب` · `مساعدة` · `التوصيل` · `الدفع`

## 8) ملاحظات مهمة

- لا تشارك ملف `.env` أو التوكنات مع أحد. غيّر `SESSION_SECRET` قبل النشر.
- الردود تُرسل فقط رداً على رسالة واردة. مسنجر يسمح بالرد ضمن نافذة ٢٤ ساعة، وواتساب يتطلب قالباً معتمداً (Template) للرسائل خارج النافذة — لذلك ردّنا فوري على الرسائل الواردة.
- إذا لم تستقبل Webhooks: تأكد أن الرابط `https` عام، وأن `VERIFY_TOKEN` مطابق، وراجع سجلات السيرفر (Console).
- البيانات كلها محلية على جهازك/خادمك — لا تُرسل إلا إلى Gemini عند تفعيل الرد الذكي.

### حدود الخطة المجانية / Meta (مهمة)
- **رقم واتساب الحالي رقم اختباري** من Meta يرسل إلى ٥ أرقام فقط. للجمهور العام تحتاج تسجيل رقم نشاطك التجاري (الخطوة ٢ في Meta).
- **التطبيق غير منشور (Unpublished)** في Meta: الرسائل تعمل مع المطورين/المختبرين فقط. للوصول لكل الزبائن قدّم التطبيق للمراجعة (App Review) واطلب صلاحية `pages_messaging`.
- **Render المجاني** ينام بعد عدم نشاط وتخزينه مؤقت: قاعدة البيانات تُعاد تهيئتها عند إعادة النشر. استخدم لوحة الأدمن ← الإعدادات ← **تنزيل نسخة / استيراد نسخة** لحفظ بياناتك.

### تغيير رقم نشاط واتساب من التطبيق
- الأدمن ← الإعدادات ← **رقم واتساب للعرض** يغيّر زر «راسلنا» فوراً (تم ضبطه على `218945343522`).
- لإرسال الردود من رقم جديد: سجّل الرقم في Meta أولاً، ثم الصق **Phone Number ID** و**Access Token** في الحقلين المخصصين في الإعدادات — يسري التغيير فوراً بدون إعادة تشغيل، وزر «تحقق من رقم النشاط» يخبرك بالرقم الفعلي.
- إذا ظهرت رسالة Meta «هذا الرقم مسجل بالفعل على واتساب»: انقل الرقم إلى تطبيق **WhatsApp Business** على جوالك (نسخة احتياطية ← تثبيت Business ← التحقق من نفس الرقم ← إكمال النقل)، ثم أعد المحاولة. أو استخدم رقمًا آخر مخصصاً للنشاط.

### المزايا المضافة حديثاً
- **رفع الصور والأيقونات من الجوال/الكمبيوتر**: في نموذج الصنف/المنتج، اختر ملف الصورة وستُرفع تلقائياً ويظهر الرابط في الحقل (الحد الأقصى ٨ ميجابايت). لا تحتاج رابطاً خارجياً.
- **ألوان ومقاسات**: فعّل الخيار في الصنف، اكتب الألوان والمقاسات مفصولة بفاصلة. المنتج يرثها تلقائياً أو تقدر تخصّه بقيمته. الزبون يختار اللون/المقاس قبل الإضافة للسلة.
- **صور متعددة + صورة لكل لون**: في نموذج المنتج ارفع عدة صور (تظهر كمعرض مصغّر تحت الصورة الرئيسية)، ولكل لون ارفع صورته الخاصة — عند اختيار اللون تتغير الصورة الرئيسية تلقائياً. الصور تُرفع من جهازك ولا تحتاج روابط.
- **تسجيل الزبون برقم الجوال**: المتجر ← «دخول الزبون» → إرسال رمز من ٦ أرقام → تأكيد → حفظ الاسم والمدينة والعنوان. بما أنه لا يوجد مزوّد SMS مجاني، الرمز يظهر في نافذة التسجيل (**وضع تجربة**) وفي الأدمن ← «الزبائن والتحقق». (لإرسال SMS حقيقي تحتاج مزوّداً مدفوعاً أو بوابة محلية.)
- **الخريطة**: زر «تحديد الموقع على الخريطة» يفتح خريطة OpenStreetMap (مجانية بلا مفتاح)، وزر «موقعي تلقائياً» يستخدم GPS ويملأ العنوان والمدينة تلقائياً عبر Nominatim. الإحداثيات تُحفظ مع الطلب.
- **الدولة والعملة**: `ليبيا` و`د.ل` كقيم افتراضية، وكلاهما قابل للتعديل من الأدمن ← الإعدادات.
- **تغيير صفحة/توكن مسنجر**: الأدمن ← الإعدادات ← «إعدادات مسنجر والصفحة»، مع زر تحقق. التغيير يسري فوراً.
- **النسخة الاحتياطية** تشمل الزبائن ورموز التحقق أيضاً.

> الصور المرفوعة تُحفظ في `public/uploads/`؛ على Render المجاني تُحذف عند إعادة النشر — استخدم زر النسخة الاحتياطية قبل التحديث إذا احتجت صوراً دائمة (أو ارفعها لتخزين خارجي لاحقاً).

### 🔗 ربط صفحة فيسبوك + التعليقات
- **نشر تلقائي على خط الصفحة**: أضف **ID الصفحة** + **Page Access Token** في الأدمن ← الإعدادات ← «صفحة فيسبوك»، ثم اكتب المحتوى في حقل «المحتوى للنشر» واضغط «📢 نشر بصفحة فيسبوك».
- **رد تلقائي على تعليقات الصفحة**: يجب إنشاء Webhook على Meta بـ object `feed` (Feed Comment Addition) + الاشتراك على `feed`. السيرفر يقرأ التعليقات ويردّ عليها عبر `replyComment` فوراً باستخدام مفتاح الصفحة.
- **تنبيه الزبون عند إتمام الطلب**: لكل طلب في الأدمن يمكن إرسال إشعار تلقائي على مسنجر أو واتساب (POST `/api/admin/orders/:id/notify`).

### 📣 خطوات بسيطة لربط صفحة فيسبوك
1. أضف صفحة فيسبوك للمتجر، ثم أضف `Page Access Token` (إعدادات ← التطبيق ← معاملات OAuth ← إنشاء رمز).
2. ضعه في `facebook_page_token` + اكتب `facebook_page_id` في الأدمن ← الإعدادات، واختبر.
3. في Meta App Dashboard → Webhooks → اختر الصفحة واشترك في `feed` (Feed Comment Addition) مع Callback URL `https://opera-ai-reply-bot.onrender.com/webhooks/facebook`.
